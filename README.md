# PhoneStore — متجر إلكتروني متكامل للهواتف والإلكترونيات

متجر ثنائي اللغة (فرنسي + عربي RTL) مبني بـ **Next.js 15 + TypeScript + Tailwind 4 + PostgreSQL (Drizzle)**.
الدفع: **عند الاستلام** · العملة: **EUR**.

## ما الذي يتضمنه

**المتجر (للزبائن)**
- صفحة رئيسية، فئات، بحث، تصفية (علامة/سعر/مخزون/عروض)، فرز، ترقيم صفحات
- صفحة منتج: ألوان وسعات بسعر ومخزون مستقل، معرض صور، مواصفات، منتجات مشابهة، بيانات SEO منظّمة (JSON-LD)
- سلة (درج جانبي + صفحة) تُعاد تسعيرها من قاعدة البيانات، مفضلة، أكواد خصم
- إتمام الطلب بدون حساب: توصيل عادي/سريع (مجاني فوق 100 €)، دفع عند الاستلام
- صفحة تأكيد الطلب + تتبّع الطلب (رقم الطلب + البريد)
- بريد تأكيد للزبون وإشعار لصاحب المتجر (اختياري عبر Resend)
- صفحات: التوصيل، الإرجاع والضمان، الخصوصية، الشروط، من نحن، اتصل بنا
- sitemap.xml وrobots.txt وروابط hreflang

**لوحة التحكم (`/admin` — بالعربية)**
- لوحة مؤشرات: إيرادات 30 يومًا، عدد الطلبات، مخطط يومي، تنبيه المخزون المنخفض
- الطلبات: بحث وفلترة بالحالة، تغيير الحالة (إلغاء الطلب يعيد المخزون تلقائيًا)، ملاحظات داخلية، طباعة
- المنتجات: إضافة/تعديل/إخفاء/حذف، خيارات (لون + سعة) بسعر ومخزون، صور، مواصفات ثنائية اللغة
- الفئات وأكواد الخصم (نسبة أو مبلغ، حد أدنى، حد أقصى للاستخدام)

**الأمان والصلابة**
- الأسعار والمخزون تُحسب دائمًا على الخادم، وإنشاء الطلب داخل معاملة مع قفل الصفوف (لا بيع زائد عن المخزون)
- فحص المدخلات بـ Zod، حقل مصيدة ضد البوتات، ترويسات أمان، جلسة إدارة موقّعة (JWT في كوكي HttpOnly)

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local      # عدّل القيم
npm run db:setup                # ينشئ الجداول ويضيف بيانات تجريبية
npm run dev                     # http://localhost:3000  (الإدارة: /admin)
```

يحتاج PostgreSQL: محليًا أو قاعدة مجانية من [Neon](https://neon.tech) (انسخ `DATABASE_URL`).

## النشر (Vercel + Neon)

1. أنشئ مشروع Neon وانسخ رابط الاتصال.
2. من جهازك نفّذ مرة واحدة على قاعدة الإنتاج:
   `DATABASE_URL="<neon-url>" npm run db:migrate`
   (لا تشغّل `db:seed` في الإنتاج إلا إن أردت بيانات تجريبية — أنشئ فئاتك ومنتجاتك من `/admin`.)
3. استورد المستودع في Vercel وأضف المتغيرات:

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط Postgres |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (قوية) |
| `AUTH_SECRET` | سلسلة عشوائية طويلة (32+ حرفًا) |
| `NEXT_PUBLIC_SITE_URL` | عنوان موقعك، مثل `https://mystore.com` |
| `NEXT_PUBLIC_STORE_NAME` | اسم المتجر |
| `NEXT_PUBLIC_CONTACT_EMAIL` / `_PHONE` / `_ADDRESS` / `_LEGAL_NAME` | بيانات الاتصال والشركة (تظهر في التذييل والصفحات القانونية) |
| `RESEND_API_KEY`, `MAIL_FROM`, `ORDER_NOTIFY_EMAIL` | (اختياري) رسائل الطلبات |
| `BLOB_READ_WRITE_TOKEN` | (اختياري) رفع الصور من لوحة التحكم عبر Vercel Blob |

## التخصيص

- **الأسعار والتوصيل والدول**: `src/config/store.ts` (حد التوصيل المجاني، رسوم التوصيل، الدول المخدومة).
- **النصوص والترجمات**: `src/dictionaries/fr.ts` و`ar.ts`.
- **الألوان والخطوط**: `src/app/globals.css` (قسم `@theme`).
- **الصور**: ارفعها من صفحة تعديل المنتج (بعد تفعيل Blob) أو الصق روابط صور. بدون صور يظهر رسم توضيحي تلقائي.

## ملاحظات مهمة قبل الإطلاق

- المنتجات والأسعار في `scripts/seed.ts` **بيانات عرض تجريبية** فقط.
- الصفحات القانونية (الشروط، الخصوصية، الإرجاع) نصوص عامة: راجعها مع مختص وأضف بيانات شركتك (الاسم القانوني، رقم التسجيل/الضريبة).
- نصوص التوصيل تذكر الأرقام (100 € / 4,90 € / 9,90 €) يدويًا؛ حدّثها إن غيّرت `store.ts`.
